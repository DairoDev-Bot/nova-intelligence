# NOVA Intelligence

An Android app that displays real-time information about your phone: processor, RAM, storage, battery, and screen, without you having to search for it.

## Download

[Download the latest version (APK)](https://github.com/DairoDev-Bot/nova-intelligence/releases/latest/download/NovaIntelligence.apk)

All versions are in [Releases](https://github.com/DairoDev-Bot/nova-intelligence/releases).

## What it shows (v0.1)

- Android model, brand, and version
- Processor and number of cores
- RAM and storage (total and free)
- Battery: level and status, live
- Screen: resolution, pixel density, and refresh rate (Hz)

## Installation

1. Download the APK from the link above.

2. Open it. If prompted by Android, allow the installation of apps from this source.

3. If Play Protect displays a warning, tap "Install anyway." This is normal for apps not from the Play Store.

## Compatibility

Android 7.0 to Android 16.

## Privacy

The app does not have internet access and does not collect data. All data is read from your phone.

## Project Status

Version 0.1: Home tab only. Coming soon: Hardware, Analytics, and Settings.

## Known Limitations

- Battery capacity in mAh cannot be read on all phones.

- Some processors are listed with their chip code instead of their brand name.

- Current versions use debug signatures: to update, uninstall the previous version first.

## How it's compiled

The APK is automatically compiled using GitHub Actions whenever changes are pushed.
